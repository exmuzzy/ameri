# Скиллы

Скиллы `grilling`, `grill-me`, `grill-with-docs`, `domain-modeling` и `to-questionnaire` взяты из
[mattpocock/skills](https://github.com/mattpocock/skills) (коммит `c55ee46`, лицензия MIT — см. `LICENSE-mattpocock-skills`).

- `/grill-me` — интервью раундами: агент строит дерево решений и задаёт вопросы с рекомендованными ответами, пока не останется неясностей.
- `/grill-with-docs` — то же интервью, но по ходу пишет глоссарий `CONTEXT.md` и ADR в `docs/adr/`.
- `/to-questionnaire` — опросник в Markdown для человека, который ответит позже (асинхронно).
- `grilling` и `domain-modeling` — базовые скиллы, от которых зависят остальные.
