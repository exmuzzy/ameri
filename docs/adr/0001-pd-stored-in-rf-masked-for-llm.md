# Персональные данные хранятся в РФ и маскируются перед отправкой в модель

В переписке и файлах менеджеров будут персональные данные клиентов — граждан РФ, поэтому по 152-ФЗ база и файлы размещаются на сервере в России. Модель DeepSeek обрабатывает данные за пределами РФ, поэтому перед вызовом модели персональные данные (ФИО, телефоны, почты, реквизиты документов) заменяются метками, а после ответа подставляются обратно.

## Consequences

- Хостинг выбирается только среди российских провайдеров; доступность API Telegram и DeepSeek с этого сервера нужно проверить.
- Маскирование — обязательный слой между ботом и моделью, в том числе при вызове Claude Code; файлы перед анализом тоже проходят через него.
