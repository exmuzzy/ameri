# Интерфейс — сайт на Streamlit

Менеджеры и Руководитель работают только через сайт на Streamlit, развёрнутый на сервере `bishkek`. Основа — прототип «Расчётка воздуховодов» (duct-calc), уже написанный на Streamlit: загрузка Спецификации → разбор моделью DeepSeek в JSON → проверки → детерминированный расчёт → XLSX по шаблону.

## Consequences

- История работы, файлы и Уточнения хранятся приложением; инструменты Руководителя читают их через API приложения.
- Модель только разбирает текст; площади, массы и цены считает код (принцип прототипа «модель не калькулятор»).
