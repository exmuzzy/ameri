# Веб-приложение на Streamlit вместо мессенджера

Заказчик полностью отказался от мессенджеров, в том числе от Telegram: Менеджеры и Руководитель работают в веб-приложении на Streamlit, развёрнутом на сервере `bishkek`. Основа — прототип «Расчётка воздуховодов» (duct-calc): загрузка спецификации → разбор моделью DeepSeek в JSON → проверка → детерминированный расчёт → XLSX по шаблону.

## Consequences

- Решения о Telegram (создание групп, webhook бота, username в @BotFather, темы «Настройка», чтение истории через Telegram API) отменены: Q5, Q7, Q15–Q16 (в части @BotFather), Q21, Q25 в прежней формулировке.
- Домен и HTTPS (Q24, sslip.io) теперь нужны для самого веб-приложения.
- История работы, файлы и вопросы Менеджеров хранятся приложением; инструменты Руководителя читают их из приложения, а не из мессенджера.
- Модель считает только разбор текста; площади, массы и цены считает код (принцип прототипа: «модель не калькулятор»).
