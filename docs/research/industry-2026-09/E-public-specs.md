## Коротко

- Найдено **10 документов**, в которых есть пластиковые воздуховоды и фасонные изделия (ПП, ПНД/ПЭ, ПВХ), плюс 2 дополнительных коротких. Все они — **открытые перечни позиций закупок на ЭТП B2B-Center** (`b2b-center.ru`, была в списке площадок). Это ведомости на поставку/изготовление, большая часть из них выписана из проектной спецификации (ссылки вида «32.25.17-ОВ2.СО», «322/1-ОВ.СО Лист 5», «…-О.ОВ2-ОЛ03»).
- **Проектов ОВ в виде PDF/DOCX/XLSX с пластиковыми воздуховодами в открытом доступе найти не удалось.** Проверено около 10 PDF/DOC проектной документации и ТЗ, пластиковых воздуховодов в них нет (список в конце). Причины:
  - `zakupki.gov.ru`, `rts-tender`, `roseltorg`, `sberbank-ast`, `fabrikant`, `tender.pro` из этой среды недоступны. WebFetch к `zakupki.gov.ru` и `roseltorg` возвращает 503.
  - `docplayer` отклоняется прокси (502).
  - Бюджет WebSearch сессии (200 запросов) исчерпан на середине работы.
  - Поисковики через curl либо показывают капчу, либо не отдают выдачу.
- Вложения («Документация от организатора») на B2B-Center открыты только зарегистрированным пользователям, поэтому **файлов-вложений нет**. Скачана только открытая часть процедуры:
  - страница извещения;
  - вкладка «Позиции». В классическом интерфейсе это `?action=positions`, по 20 строк на страницу. В новом интерфейсе (`/app/market-next/`) страница показывает 10 строк, а полный список отдаёт тот же POST-запрос, который делает сама страница: `https://www.b2b-center.ru/market/openapi/positions/get_positions_aggregates_list` с телом `{"trade_id":{"value":<№>},"offset":0,"limit":100}`.

  В API количество приходит умноженным на 1000: 37000 соответствует «37». Это сверено с HTML-страницей (например, «3,5» у №4335899). В таблицах ниже количество уже в виде, как на странице.
- **Персональных данных в позициях нет.** Контакты организатора скрыты («Доступно зарегистрированным пользователям»). На страницах есть только название организатора (юрлицо) и адрес поставки (площадка предприятия). При подготовке эталона их стоит убрать.
- **Лицензия во всех случаях неясна.** Это открытая часть извещений коммерческих закупок на частной ЭТП, а не официальные документы госорганов. Открытой лицензии нет. В «Пользовательском соглашении» B2B-Center (`https://www.b2b-center.ru/help/Пользовательское_соглашение/`) условий переиспользования открытой части я не нашёл.

  Репозиторий ameri публичный, поэтому для эталона предлагаю брать только строки номенклатуры: без названия организатора, номера процедуры и адреса. Решение за человеком.
