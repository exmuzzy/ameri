# Протокол стартового интервью

Решения, без которых нельзя развернуть бота и провести Опрос настройки в Telegram. Термины — в `CONTEXT.md`, необратимые решения — в `docs/adr/`.

## Раунд 1 — 2026-09-26

Заказчик принял все рекомендации.

| № | Вопрос | Решение |
|---|---|---|
| Q1 | Что такое «Z-код» | Claude Code, подключённый к DeepSeek |
| Q2 | Руководитель и Администратор | Две роли с разными правами; на старте один человек может совмещать обе |
| Q3 | Персональные данные | Будут данные клиентов — граждан РФ: хранение в РФ, маскирование перед отправкой в модель ([ADR-0001](adr/0001-pd-stored-in-rf-masked-for-llm.md)) |
| Q4 | Сервер | Своего нет, подбираем; страна и провайдер — в следующем раунде |
| Q5 | Создание Группы | Бот выдаёт ссылку, по которой его добавляют в группу сразу администратором; бот сам регистрирует Группу в репозитории |
| Q6 | Как бот узнаёт Руководителя | Telegram ID первого Руководителя в конфиге репозитория; остальных он добавляет командами в Telegram |
| Q7 | Где идёт Опрос настройки | Общая настройка — в личке с ботом; настройка конкретной Группы — в теме «Настройка» этой Группы |
| Q8 | Утверждение изменений Харнеса | После подтверждения в Telegram бот сразу коммитит в основную ветку; откат через git. Pull request — позже |
| Q9 | Репозиторий Харнеса | Этот же репозиторий (`exmuzzy/ameri`), каталог `harness/` |
| Q10 | Стек | Выбор за исполнителем; предложение — Python + aiogram 3 |
| Q11 | Бюджет | До 2 000 ₽/мес на сервер, до $20/мес на DeepSeek на период настройки; бот следит за расходом |
