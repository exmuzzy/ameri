| Q35 | Исправления | Исправление → Правило → проверка на Эталонах → подтверждение → коммит |
| Q36 | Наблюдение Руководителя | Страница «История» в приложении |
| Q37 | Нарезка метража | Метраж больше 2 м — отрезки по 1500 мм плюс остаток (3.2 мп → 1500 + 1500 + 200). Метраж до 2 м включительно не режется — одна штука этой длины; больше 1500 мм — нестандарт 1,5 / 3 (2 мп → 1 × 2000). Так же «N шт по M м»: N штук длиной M м («2 шт по 2 м» → 2 × 2000, нестандарт), как «L=2000». Строка «4 шт, 8 м» без «по» не трактуется: длина штуки — из разбора модели. Подтверждено заказчиком 2026-10-08 (резка всего метража по 1500 + остаток), уточнено заказчиком 2026-11-01 (до 2 м — одна штука). **Сделано** в обёртке ameri (`actions._install_short_meters_as_one_piece`, `actions.pieces_of_meters`) |
| Q38 | Зонт с одним размером | Размер — патрубок; купол = патрубок + 2 × 500 (вылет), если не указан: ф500 → купол 1500. Изменено заказчиком 2026-10-09 (было 2 × патрубок с 2026-09-27); зонт менеджер всегда проверяет вручную — в ответе расчётки зонты перечислены отдельно. **Сделано** в обёртке ameri (`actions.umbrella_with_dome`, `actions.result_notes`) |
| Q39 | Заголовки без количества («Вытяжка из химлаборатории») | Исправить в коде прототипа: считать заголовком раздела, как «Система В1». **Сделано** 2026-09-27 в обёртке ameri (`actions.preview_without_headings`): строка без количества, типа и размеров в расчётку не идёт; с размерами, но без количества — красная. Подтверждено заказчиком 2026-09-27: DeepSeek путает заголовок с позицией, ему нужна подсказка кодом |
| Q40 | «фланец20», «ф20» в спецификациях | Конец фланцевый (стандартный фланец компании для сечения), позиция не останавливает расчёт, менеджер уточняет у клиента: шинорейка 20, толщина 20 или полка 20. Решение заказчика 2026-09-27 (вариант б). **Сделано** в обёртке ameri (`actions.result_notes`); пока нет Q41, фланец считается, только если в чате выбран тип «Фланец» |
| Q41 | Соединения по торцам («раструб/труба») | Доработка прототипа после запуска сайта |
| Q53 | «ш20» и другие непонятные уточнения клиента | Позиция считается по понятной части (сечение, длина, количество; толщина — из таблицы), строка красная, в наименование дописывается «УТОЧНИТЬ: что значит «ш20»?». Не остаётся 0 ₽ и не уходит в покупные из-за толщины 20 мм. Решение заказчика 2026-10-31. **Сделано** в обёртке ameri (`actions._install_unclear_markers`); список маркеров — `harness/duct_calc/params.yaml`, `unclear_markers`. |
| Q54 | Коэффициенты перехода прямоугольник–круг | Стандартный круглый фасон («фасон цилиндр»): раскрой 1,5, работа 2,7; прототип давал «нестандарт фасон» (работа 3). Формула площади прежняя. Решение заказчика 2026-11-02. **Сделано** в обёртке ameri (`actions._install_rect_round_as_round_fitting`) |
| Q55 | Работа при стенке 2 мм | Коэффициент на работу + 0,15 к текущему у любой рассчитанной позиции со стенкой ровно 2 мм (из таблицы толщин или из спецификации): прямик 2,4 → 2,55, фасон 2,7 → 2,85, нестандарт, шибер и клапан 3 → 3,15. Материал (ПП или ПНД) не важен, раскрой не меняется. Решение заказчика 2026-11-12. **Сделано** в обёртке ameri (`actions._install_thin_wall_work`, `actions.thin_wall_work_m`) |
