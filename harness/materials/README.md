# Материалы отрасли

Справочник, на который опирается ассистент: названия изделий и их синонимы, нормативы, типовые размеры у производителей, химическая стойкость, работа на улице, покупное оборудование. На сайте — страница «Материалы отрасли»; ассистент получает подходящие к вопросу разделы и даёт на них ссылки.

## Формат файла

```markdown
# Название материала

_Обновлено: 2026-09-26._ Одна-две фразы: о чём материал и как им пользоваться.

## Название раздела {#id-razdela}

Текст раздела: факты, таблицы, оговорки.

Источники: [Название источника](https://...), обращение 2026-09-26.
```

- Имя файла — `NN-<id>.md`: номер задаёт порядок на сайте, `<id>` попадает в ссылку `/materials?doc=<id>&section=<id-razdela>`.
- **Идентификаторы разделов `{#...}` не меняют и не удаляют:** на них ссылаются ответы в чатах и правила харнеса. Устаревший раздел помечают «устарело» и дают ссылку на новый.
- У каждого раздела есть источник со ссылкой. Непроверенное помечают «(не проверено)». Если источники расходятся — показывают расхождение, а не среднее.
- Раздел — не длиннее ~3 500 знаков: к вопросу ассистенту подкладываются не больше трёх разделов, длинный текст обрезается.
- Цифры (концентрации, температуры, размеры) — только из источников. Цены конкурентов в материалы не кладут: цену считает расчётка.
- `python -m pytest -q` проверяет формат: заголовок, дата «Обновлено», явные `{#id}`, источник в каждом разделе, ссылки из правил на существующие разделы.

Как материалы регулярно пополняются — `prompts/industry-materials.md`.
